# 七帝爭霸 · Emperor Life

> 一款歷史帝王人生模擬器與共享世界模擬遊戲 (Historical Emperor Life Simulator + Shared World Simulation)

七位中國歷史上赫赫有名的開國之君被置於同一個虛構時代：
- **秦始皇（嬴政 · 秦）**
- **漢高祖（劉邦 · 漢）**
- **隋文帝（楊堅 · 隋）**
- **唐高祖（李淵 · 唐）**
- **宋太祖（趙匡胤 · 宋）**
- **明太祖（朱元璋 · 明）**
- **清太宗（皇太極 · 清）**

玩家選擇扮演其中一位帝王，而其餘六位帝王由自主 AI 控制。每年經歷一個回合，包含全國事件決策、經濟治理、軍事征伐、文武任用、各國外交斡旋以及全天下的風雲變幻。

---

## 🎮 遊戲特色

- **九州天下風雲圖（SVG 共享世界輿圖）**：
  - 35 個風格化地域板塊，實時顯示勢力歸屬、軍力、人口、地形與糧餉產出。
  - 攻佔鄰近敵境時，地圖即時動態變更版圖顏色與邊界。
- **七位開國君王與性格系統**：
  - 各君王具備集權、擴張、軍事、治國、外交、任賢等多維度性格，直接驅動 AI 決策邏輯。
- **名臣良將天團**：
  - 各勢力配備專屬開國功臣（如王翦、韓信、李靖、蕭何、徐達、多爾袞等），具備年齡、能力值與生卒演進。
- **年度大計與隨機事件**：
  - 包含河患、大稔、蝗災、腐敗、異人出山、刺客、金丹、神機火器、降將等豐富事件，每件事提供 3–5 種權衡決策。
- **推演戰爭系統**：
  - 綜合軍隊規模、統帥加成、士氣、補給線、地形與天命隨機因子，絕非無腦戰鬥。
- **天下大勢速報（World News）**：
  - 每年生成其他六國的結盟、募兵、天災、拓土與攻防快訊。
- **壯麗帝王列傳（End Screen）**：
  - 崩殂或統一天下後，呈現詳盡起居注、享年、在位年數、極限版圖、統一天下戰績紀錄。
- **種子隨機系統（Seed System）**：
  - 支援 URL 參數（如 `?seed=xxxx`），同一種子可精準重現歷史推演軌跡。

## 🚀 快速開始

### 本地運行
```bash
# 安裝依賴
npm install

# 啟動開發伺服器
npm run dev

# 或啟動構建預覽
npm run preview
```

瀏覽器訪問：`http://localhost:5173/`

### 構建發布 (GitHub Pages)
```bash
npm run build
```
產物將輸出至 `dist/` 目錄，支援直接部署至 GitHub Pages。
